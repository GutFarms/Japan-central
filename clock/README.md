# JC Time — Japan & Central

egui / eframe dual world clock with rich custom graphics for **both** timezones.

## Features
- Side-by-side **Japan (Tokyo / JST)** and **Central (Chicago / CT with DST)** panels
- Analog clocks with glow rings, smooth second hands, and hour marks
- Large digital time + full date
- Deep navy atmosphere matching the CYD monitor palette

## Run from source

```bash
cd clock
cargo run --release
```
