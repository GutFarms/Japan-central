# HUP codec stub (standalone)

Tiny **reference** crate for the JCHC Hasher UART Protocol.  
**Not** the miner firmware — integrate these frames into your separate ESP32 miner project when you assemble JCHC-1.

```bash
cd hardware/esp32-asic-controller/firmware-stub
cargo test
```

See `../docs/hasher-uart-protocol.md` for the full command set.
